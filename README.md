# AstroScope (Zodiac & Tarot Information System)

# Live Demo
https://nangkmoeoo.github.io/AstroScope/

## Description
AstroScope is a simple astrology web project that allows users to explore zodiac signs, horoscopes, zodiac calendar, and tarot-based fortune insights.

## Features
- Zodiac sign detection by birth date
- Horoscope information
- Detailed zodiac sign information
- Tarot card selection
- planet information
- Simple and user-friendly UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository
2. Open `home.html` in any web browser
